❓ **Q2 — 全域委託與局部綁定 (Event Delegation vs Local Binding)**：底層如何處理事件的實體監聽。

選項：
- **A (推薦)** **全域事件委託 (Event Delegation)**：

- **解耦徹底**：繪製與事件生命週期完全分離，未來如果要改成 `click` 或加入 touch 支援，只需修改全域監聽器一處，不需要對 DOM 重新綁定事件。

❓ **Q4 — 事件委託綁定時機與目標容器 (Binding Target & Timing)**：全域事件委託要綁定在什麼地方？什麼時候綁定？

❓ **Q5 — 氣泡事件目標解析 (Event Bubble Resolution)**：點擊發生後，如何向上尋找掛載了 `_abcElement` 的節點？

選項：
- **A (推薦)** **使用經典的 `while` 迴圈冒泡尋找**：
  ```typescript
  let curr: any = e.target;
  while (curr && curr !== targetEl) {
      if (curr._abcElement) {
          this.notifySelect(curr._abcElement);
          break;
      }
      curr = curr.parentNode;
  }
  ```
  這能確保不論點擊的是 SVG 內部哪一層的子路徑或文字，都能順利冒泡找到其關聯的 `ABCAbsoluteElement`。
- **B** **只看 `e.target` 本身，不冒泡**：
  如果點擊的是 group (`<g>`) 內部的 sub-path 則會漏判。

➡️ 推薦 **A**：強健性高，完全適配 SVG 的嵌套結構。

❓ **Q6 — `bindInteraction` 容錯設計 (API Signature of bindInteraction)**：傳入的 SVG 元素可以是單一元素、陣列、甚至是 null，我們該如何統一處理？

- **A (推薦)** **在 `bindInteraction` 內統一包裝成陣列處理**：
  ```typescript
  bindInteraction(svgEl: any, absEl: ABCAbsoluteElement): void {
      if (!svgEl || !absEl) return;
      const elements = Array.isArray(svgEl) ? svgEl : [svgEl];
      for (const el of elements) {
          if (el) {
              (el as any)._abcElement = absEl;
          }
      }
  }
  ```
  因為 `printer.printSymbol` 等方法可能回傳 `SVGElement` 或 `SVGElement[]`，這樣做能讓呼叫側完全不需手動判斷陣列，直接丟進去即可。
- **B** **只接受單一 `SVGElement`**，呼叫側必須自己寫 `Array.isArray` 分流。

➡️ 推薦 **A**：大幅減輕呼叫側 (五線譜/簡譜渲染模組) 的代碼噪音，提升 Seam 的 Depth。
